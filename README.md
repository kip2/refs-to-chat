# Refs to Chat

右クリックで、選択範囲・ファイル・フォルダの参照（`@src/app.ts#5-10` など）を、Claude のチャットに追加する VS Code 拡張です。

[Claude Code](https://www.anthropic.com/claude-code) の公式の VS Code 拡張（この README では「公式拡張」と呼びます）と一緒に使います。

> 個人が作った非公式の拡張です。Anthropic とは関係ありません。

<!-- 上の引用と下の注意を、別のかたまりとして表示する -->

> [!WARNING]
> **この拡張は、一部の操作でクリップボードの中身を書き換えます。**
> 
> 書き換えるのは、エクスプローラーと Markdown のプレビューから追加したとき（初期設定のとき）と、チャットに追加できなかったときです。
>
> 書き換えたくない場合は、次のようにしてください。
>
> - 設定 `refsToChat.explorerClipboard` と `refsToChat.previewClipboard` を `keep` にする。クリップボードを使わずに入れます（くわしくは「[設定](#設定)」）
> - テキストとして開けないもの（フォルダや画像など）は、`keep` にしてもクリップボードを使います。これも避けたいときは、エクスプローラーから追加しないでください
> - エディタの右クリックでも、チャットに追加できなかったときは、参照をクリップボードにコピーします（追加できたときは、クリップボードを使いません）

## できること

| 右クリックする場所 | メニュー | チャットに入る参照 |
| --- | --- | --- |
| エディタ（範囲を選択している） | 選択範囲をClaudeのチャットに追加 | `@src/app.ts#5-10` |
| エディタ（何も選択していない） | このファイルをClaudeのチャットに追加 | `@src/app.ts` |
| エクスプローラーのファイル | Claudeのチャットに追加 | `@src/app.ts` |
| エクスプローラーのファイル（複数選択） | Claudeのチャットに追加 | `@src/app.ts @src/util.ts @README.md`（選んだ順に空白でつなぐ） |
| エクスプローラーのフォルダ | Claudeのチャットに追加 | `@src/components/`（貼り付けで入れる） |

チャットの入力欄に参照が入ります。

エディタの 2 つのメニューは、コマンドパレット（`Ctrl+Shift+P`）からも「Refs to Chat: 選択範囲をClaudeのチャットに追加」のように呼べます。

### チャットへの入れ方

エディタで使用した場合、公式拡張のコマンドを介してチャットに参照を追加します。
次のものは、公式拡張のコマンドでは追加できないので、参照をクリップボードにコピーしてから、チャットの入力欄に貼り付けます。

- テキストとして開けないもの（フォルダや画像など）
- エクスプローラーのファイルと、Markdown のプレビューで選んだところ（初期設定のとき）

追加されていなければ、クリップボードにある参照を、チャットの入力欄に貼り付けてください。

チャットに追加できなかったときは、参照をクリップボードにコピーします。
ファイル名に改行などの特別な文字が入っているものは、チャットにもクリップボードにも入れません。

## Markdown のプレビューから追加する

Markdown のプレビュー（`Ctrl+Shift+V` や `Ctrl+K V` で開く、VS Code に組み込みのもの）で文章を選んで右クリックし、「選択範囲をClaudeのチャットに追加」を選びます。
元の Markdown ファイルの、選んだところの行の参照がチャットに入ります。

| 右クリックする場所 | メニュー | チャットに入る参照 |
| --- | --- | --- |
| Markdown のプレビュー（文章を選択している） | 選択範囲をClaudeのチャットに追加 | `@docs/guide.md#12-18`（元のファイルの行） |

初期設定では、参照をクリップボードにコピーしてから、チャットの入力欄に貼り付けます。
クリップボードを使いたくないときは、設定 `refsToChat.previewClipboard` を `keep` にしてください（くわしくは「[設定](#設定)」）。

## 設定

エクスプローラーと Markdown のプレビューからチャットに追加するときに、クリップボードを使うかどうかを設定で変えられます。

  <tr>
    <th>設定</th>
    <th>値</th>
    <th>動き</th>
  </tr>
  <tr>
    <td rowspan="2"><code>refsToChat.explorerClipboard</code></td>
    <td><code>use</code>（初期設定）</td>
    <td>クリップボードを使う。エクスプローラーのファイルを、開かずに貼り付けで入れる。そのためクリップボードの中身が書き換わる</td>
  </tr>
  <tr>
    <td><code>keep</code></td>
    <td>ファイルではクリップボードを使わない。かわりに、ファイルを一瞬開いて、公式拡張のコマンドで入れる。タブが一瞬開いて閉じる。もともと開いていたタブや選択範囲は、そのまま残る</td>
  </tr>
  <tr>
    <td rowspan="2"><code>refsToChat.previewClipboard</code></td>
    <td><code>use</code>（初期設定）</td>
    <td>クリップボードを使う。Markdown のプレビューで選んだところを、元のファイルを開かずに貼り付けで入れる。そのためクリップボードの中身が書き換わる</td>
  </tr>
  <tr>
    <td><code>keep</code></td>
    <td>クリップボードを使わない。かわりに、元のファイルを一瞬開いてその行を選び、公式拡張のコマンドで入れる。元のファイルを横に表示していれば、そのエディタを使う</td>
  </tr>
</table>

`keep` にしても、テキストとして開けないもの（フォルダや画像など）は、クリップボードを使います。チャットに追加できなかったときも同じです。エディタの右クリックは、この設定に関係なく、公式拡張のコマンドで入れます。

## 必要なもの

- VS Code 1.94 以上
- 公式拡張（`anthropic.claude-code`）
- 信頼したワークスペースで使うこと（制限モードでは動きません）

WSL や SSH 先のフォルダを VS Code で開いているときも、この拡張は手元の PC に入れるだけで使えます。

## インストール

Marketplace には出していません。

VSIX ファイルからインストールします。

1. [Releases](https://github.com/kip2/refs-to-chat/releases) から `refs-to-chat-<バージョン>.vsix` をダウンロードする
2. VS Code の拡張機能ビューを開き、右上の「…」→「VSIX からのインストール…」でダウンロードしたファイルを選ぶ

手順 2 のかわりに、コマンドで入れることもできます。

```bash
code --install-extension refs-to-chat-<バージョン>.vsix
```

## 注意

- チャットの起動に 15 秒以上かかると、参照が入らないことがあります。そのときは、何も表示されません。チャットの読み込みが終わってから、もう一度追加してください。
- 公式拡張の更新で動きが変わると、チャットに追加できなくなることがあります。そのときは、参照をクリップボードにコピーします。
