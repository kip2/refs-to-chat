# 手動テストの手順

自動テスト（`npm test`・`npm run test:integration`）では、公式の Claude Code 拡張を無効にしています。
そのため、「チャットの入力欄に参照が本当に入るか」は、人が VS Code で確かめる必要があります。
リリースの前に、この手順で確かめてください。

## 準備

1. VSIX を作って入れる

   ```bash
   npm run package
   code --install-extension right-click-mention-<バージョン>.vsix
   ```

   同じバージョンのまま入れ直すと、VS Code が古い拡張の情報を覚えたままになり、変更が反映されないことがあります。
   試すたびに `package.json` の `version` を上げるか、VS Code を終了して `%APPDATA%\Code\CachedProfilesData\__default__profile__\extensions.user.cache` を消してください。

2. コマンドパレット（`Ctrl+Shift+P`）で「Developer: Reload Window」を実行する
3. 公式の Claude Code 拡張が入っていて、ログインしていることを確かめる
4. 拡張機能ビューで、`Right Click Mention` が今回のバージョンになっていることを確かめる
5. ログの見方を確かめておく
   - 公式拡張のログ: メニューの「表示」→「出力」（`Ctrl+Shift+U`）を開き、出力パネルの右上の一覧から「Claude VSCode」を選ぶ
   - この拡張のエラー: コマンドパレットで「Developer: Toggle Developer Tools」を実行し、開いた画面の「Console」（コンソール）を見る

結果は、下の表の「結果」の列に ✅ / ❌ で書き込みます。
❌ のときは、何が起きたかをメモし、上の 2 つのログも見てください。

## B. エクスプローラーから追加する（初期設定 `paste`）

設定 `rightClickMention.explorerFiles` が初期設定の `paste` になっていることを確かめてから試します。設定は、次のどちらかで見たり変えたりできます。

- `Ctrl+,` で設定画面を開き、「Right Click Mention」で検索して、「Explorer Files」で選ぶ
- settings.json に `"rightClickMention.explorerFiles": "paste"` と書く（書いていなければ `paste`）

| No. | 手順 | 期待する結果 | 結果 |
| --- | --- | --- | --- |
| B-1 | 開いていないファイルを右クリック →「Claudeのチャットに追加」 | `@ファイル` が貼り付けられ、「チャットに貼り付けました」の通知が出る。ファイルのタブは開かない（一瞬も出ない） | |
| B-2 | ファイル 2 つとフォルダ 1 つを選んで追加 | `@ファイル1 @フォルダ/ @ファイル2` のように、選んだ順に 1 回で貼り付けられる | |
| B-3 | 開いているファイル（範囲を選んでおく）を追加 | `@ファイル`（行番号なし）が貼り付けられる。タブも選択範囲もそのまま | |
| B-4 | 何かをコピーしてから B-1 をする | クリップボードの中身は `@ファイル` に置き換わる（仕様） | |
| B-5 | 設定画面（`Ctrl+,`）で「Right Click Mention」と検索する | 「Explorer Files」の設定があり、`paste` と `open` を選べる。それぞれ説明が出る | |
| B-6 | B-1 のあと、チャットの入力欄をクリックして `Ctrl+V` を押す | `@ファイル` がもう一度入る（自動で入らなかったときも、こうすれば入れられる） | |

## C. エクスプローラーから追加する（設定 `open`）

設定 `rightClickMention.explorerFiles` を `open` に変えてから試します。次のどちらかで変えられます。

- `Ctrl+,` で設定画面を開き、「Right Click Mention」で検索して、「Explorer Files」で `open` を選ぶ
- settings.json に `"rightClickMention.explorerFiles": "open"` と書く

試し終わったら、`paste` に戻してください。

| No. | 手順 | 期待する結果 | 結果 |
| --- | --- | --- | --- |
| C-1 | 開いていないファイルを右クリック →「Claudeのチャットに追加」 | `@ファイル` が入る。一瞬開いたタブは閉じる | |
| C-2 | 開いているファイル（範囲を選んでおく）を右クリックして追加 | `@ファイル`（行番号なし）が入る。タブは残り、選択範囲もそのまま | |
| C-3 | エディタを左右に分けて、ファイル X を右側にだけ開き、左側で別のファイル Y を選んだ状態で、エクスプローラーから X を追加する（手順は表の下） | `@X` が入る。左側は Y のまま（X のタブが一瞬できても閉じる）。右側の X のタブは残る | |
| C-4 | ファイルを 3 つ選んで追加 | 3 つとも入る。タブは残らない | |
| C-5 | フォルダを右クリックして追加 | `@フォルダ/` がチャットの入力欄に貼り付けられ、「チャットに貼り付けました」の通知が出る | |
| C-6 | 画像ファイル（`.png` など）を追加 | `@画像` が貼り付けられる | |
| C-7 | ファイルとフォルダを混ぜて選んで追加 | ファイルはそれぞれ入り、フォルダは最後にまとめて貼り付けられる | |
| C-8 | プレビュー（斜体のタブ）で別のファイルを開いた状態で C-1 をする | プレビューのタブは消えない | |

C-3 の手順:

1. ファイル X（例: `README.md`）を開く
2. `Ctrl+\` で右に分割する（右側にも X が開く）
3. 左側の X のタブを閉じる（X は右側にだけある状態になる）
4. 左側で別のファイル Y（例: `package.json`）を開いてクリックする（左側が選ばれた状態になる）
5. エクスプローラーで X を右クリック →「Claudeのチャットに追加」

## F. Remote（WSL・SSH）

手元の PC に入れるだけで動くことを確かめます。始める前に、次を済ませておいてください。

- WSL を試すとき: WSL 拡張（`ms-vscode-remote.remote-wsl`）を入れ、`wsl --install` を済ませておく
- SSH を試すとき: Remote - SSH 拡張（`ms-vscode-remote.remote-ssh`）を入れ、SSH 先に接続できるようにしておく
- 公式拡張は、リモート側にも入れる。入っていないときは、公式拡張の案内に従ってリモート側に入れる（この拡張ではなく、公式拡張の都合です）
- この拡張（Right Click Mention）は、手元の PC にだけ入れる。リモート側には入れない

B-1 は設定 `paste`、C-1・C-5 は設定 `open` にして試します。

| No. | 手順 | 期待する結果 | 結果 |
| --- | --- | --- | --- |
| F-1 | 「WSL: Connect to WSL」で WSL のフォルダを開き、A-1・B-1・C-1・C-5 をする | どれも入る（参照のパスは WSL 側のパス） | |
| F-2 | Remote-SSH で SSH 先のフォルダを開き、A-1・B-1・C-1・C-5 をする | どれも入る | |
| F-3 | F-1・F-2 で、拡張機能ビューの「ローカル - インストール済み」に `Right Click Mention` があり、リモート側に入れていないことを確かめる | リモート側に入れなくても動いている | |
